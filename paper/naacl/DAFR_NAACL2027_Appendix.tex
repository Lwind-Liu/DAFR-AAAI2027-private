This supplement reports the complete benchmark tables, the matched geometry controls, and the reproducibility details for the deterministic DAFR execution layer. The main paper's claims are limited to typed action--evidence encoding, joint-risk execution constraints, and certificate-based diagnosis and repair. The matched studies do not claim that geometric code is more expressive or intrinsically safer than unrestricted predicates.

\section{Evaluation Protocol}

\paragraph{AgentDojo.}
AgentDojo v1.2.2 contains Banking, Slack, Travel, and Workspace. We evaluate DeepSeek V4 Flash, GPT-5.4-mini, and Claude Haiku 4.5 on 71 clean and 585 adversarial cases. The clean/attack counts are 16/144, 21/105, 20/140, and 14/196 for the four suites. Clean utility, attack utility, and ASR are unweighted macro-averages over suites.

\paragraph{Agent Security Benchmark.}
The ASB comparison contains 204 cases with DeepSeek V4 Flash. It reports utility, task success, and ASR. The reported DAFR run uses the benchmark's source-tagged runtime configuration; the source setting is part of the threat model and should not be generalized to settings in which provenance is unavailable.

\paragraph{Aggregation and result provenance.}
The main AgentDojo protocol uses four suites (71 clean and 585 attacked episodes). The archived three-suite subset contains 57 clean and 389 attacked episodes; its 88.1\% clean and 83.2\% attack utility for DAFR are different aggregates, not alternative estimates for the four-suite table. For metric $x$, suite macro-averaging is $\bar{x}=\frac{1}{4}\sum_{s=1}^{4}x_s$, rather than pooling all episodes. The four-suite DAFR aggregate is 87.5\% clean and 81.4\% attack utility.

The retained GPT baseline table combines earlier three-suite document aggregates with Workspace reruns; the DAFR row is recorded as a four-suite rerun. These baseline rows must not be described as newly reproduced end-to-end runs. The plotted multi-model tables retain archived aggregates; paired statistical comparisons require the underlying episode outcomes. The ASB aggregate specifies seed 17, stratified attack sampling, round-robin case sampling, shared workflow plans, and source-tagged tool provenance. Its task-success score checks completion of required normal tools, while ASR is the stored attack-goal match or an executed attacker-tool trace. These protocol choices limit direct comparison with other ASB settings.

\paragraph{Execution boundary.}
DAFR runs after a planner proposes a concrete call and before the trusted runtime executes it. The deterministic typed field interface validates registered fields and binds them to shared effect roles. The action--evidence encoder retains field identity, evidence source, authorization, and state relations. No language model is used by the execution verifier or by the matched geometry controls.

\section{Matched Geometry and Certificate Studies}

The membership arms share the same risk vectors; the repair arms share the same typed actions, evidence, and candidate transformations. Axis-ifelse checks each risk coordinate independently. Geometry evaluates one shared joint-risk region. The equivalent predicate computes the same halfspace and norm inequalities with ordinary arithmetic and is included as an implementation-equivalence control. A Boolean-only interface has no repair operator. Its zero-repair entry in the archived runner is fixed by construction and is excluded from empirical comparisons here.

The joint-risk suite contains 512 four-dimensional vectors. Every coordinate is below its independent 0.8 threshold, while 25 vectors exceed the shared joint budget. Geometry and the equivalent predicate reject the same 25 vectors. The repair suite contains 256 local write cases: 192 have a safe candidate obtained by removing an unsupported optional destination, and 64 require blocking because the destination is semantically required. Geometry and a predicate supplied with the same repair oracle recover the same 192 actions. The equality is expected because the same executable repair transformation is used in both arms; it does not show an intrinsic geometric repair advantage.

We additionally audited 614 saved AgentDojo decision records. Four records were malformed and 610 were well formed. Rechecking the recorded hard margins with an equivalent slack predicate agreed on 610/610 records; 546 were allowed and 64 were blocked or clarified. This is a saved-certificate consistency audit, not a new planner replay, external execution, or utility/ASR measurement.

\paragraph{Fixed-family stress test.}
A 64-case in-process suite crosses fresh and stale state with four fixed injection families: forged approval or runtime metadata, policy-override instructions, Chinese webpage instructions, and fabricated prerequisite claims. The runtime blocks 64/64 injected writes, including 32/32 fresh-state and 32/32 stale-state cases. An unprotected local executor performs 64/64 writes. The suite has no external side effects and is reported as a mechanism stress test rather than an adaptive-attack result.

\section{Reproducibility Record}

The evaluated configuration uses seven shared effect roles, 45 action--evidence coordinates, 13 hard constraint templates, and one soft confidence facet. Coefficients and risk budgets are configuration constants; freezing them before scoring does not substitute for a parameter-sensitivity analysis. Every decision records the concrete call, selected constraints, margin vector, source links, and final decision. The benchmark comparisons use fixed case sets and report malformed or blocked calls through the benchmark's native scoring functions. No matched geometry case invokes a real external tool.

The repository contains the benchmark manifests, raw decision records, aggregation scripts, and the matched geometry runner. The local suites should be interpreted as mechanism tests: they establish coupled-risk and certificate behavior under controlled inputs, while AgentDojo and ASB provide the task-level utility and observed attack outcomes.
