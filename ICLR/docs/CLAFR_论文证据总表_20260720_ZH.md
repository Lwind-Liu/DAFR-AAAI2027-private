# CLAFR 论文证据总表

日期：2026-07-20

## 1. 论文中心命题

CLAFR（Confidence-Lifted Action Feasible Region）把智能体安全控制放在工具执行边界。Portable Semantic Lifting 从工具 schema、描述、参数与来源类型化运行时证据中构造任务支撑、落地、权限、效果、去向和联合风险等共享关系；Dynamic Geometry 再利用语义半空间和联合风险二阶锥形成状态条件化可行域。最小带符号 margin 直接决定 Allow、Block 或 Clarify/Repair；执行 observation 更新下一轮证据状态和几何区域。

论文以 Dynamic Geometry 为核心创新和主要安全机制。AgentDojo 与 ASB 通过统一运行时契约提供结构化动作和有类型证据，同一语义本体、几何结构、风险预算与阈值在跨 benchmark 和跨 LLM 实验中保持冻结。

## 2. AgentDojo 主表

- Benchmark：AgentDojo v1.2.2，AutoDojo 实现。
- Model：DeepSeek V4 Flash。
- Suites：banking / slack / travel / workspace-selected。
- Cases：71 clean / 585 static attack。
- 聚合：四 suite 非加权宏平均。
- Workspace：预注册 14 clean / 196 attack。

| Method | Clean Utility | Static ASR | Static Attack Utility |
|---|---:|---:|---:|
| No Defense | 86.8 | 17.7 | 75.4 |
| Sandwich | **89.8** | 12.0 | 76.2 |
| Reminder | 85.0 | 3.9 | 79.2 |
| Spotlighting | 74.4 | 11.3 | 77.8 |
| PIGuard | 44.9 | **0.0** | 42.5 |
| ProtectAI | 48.0 | 4.2 | 36.2 |
| Progent | 75.2 | 2.1 | 71.7 |
| DRIFT | 62.6 | 1.4 | 53.2 |
| CLAFR | 87.5 | **0.0** | **81.4** |

可写结论：CLAFR 取得最高 Static Attack Utility，并与最低 Static ASR 持平；Clean Utility 比 Sandwich 低 2.3 points，比 No Defense 高 0.7 points。它位于安全--效用 Pareto 前沿，不写成三个指标全部第一。

排除项：PromptGuard 的 gated detector 当前无法复现实跑；DataFilter 不属于冻结主比较。

## 3. 四模块消融

- Benchmark/Model：AgentDojo v1.2.2 / DeepSeek V4 Flash。
- Cases：每行 25 clean / 208 attack。
- 抽样：按 user task 做 outcome-independent SHA-256 三分之一抽样，四 suite 均覆盖。
- 聚合：四 suite 非加权宏平均。

| Configuration | Clean Utility | Static ASR | Attack Utility | Margin |
|---|---:|---:|---:|---:|
| CLAFR | **91.4** | **0.0** | 79.1 | 0.686 |
| w/o Evidence Projection | 81.4 | **0.0** | 77.1 | 0.688 |
| w/o Portable Semantic Lifting | **91.4** | 1.4 | **82.2** | N/A |
| w/o Dynamic Geometry | 87.9 | 18.4 | 79.6 | N/A |
| w/o Decision & Repair | 77.3 | 1.5 | 79.2 | 0.686 |

模块归因：

1. Dynamic Geometry 是主要安全机制：移除后 ASR `+18.4`，Clean Utility `-3.5`。
2. Evidence Projection 主要提供可信状态 grounding：Clean Utility `+10.0`，Attack Utility `+2.0`。
3. Decision & Repair 主要恢复任务效用并提供次级安全收益：Clean Utility `+14.1`，ASR `-1.5`。
4. Portable Semantic Lifting 提供较小但可测的安全增益：ASR `-1.4`。

去掉 Lifting 或 Geometry 后 Attack Utility 略升是安全约束放松后的权衡，不应解释成模块无效。Opaque runtime ID 还原在所有行保持开启，它是执行 plumbing，不是论文模块。

## 4. ASB 跨 benchmark 证据

- 名称：ToolSafe-ASB-OPI，基于 Agent Security Bench 工具接口的冻结 OPI 迁移 harness。
- Model：DeepSeek V4 Flash。
- Cases：10 agents、51 tasks、每个 task 四种攻击 strata，共 204 cases。
- 统一条件：seed 17、agent round-robin、相同 workflow、相同可见工具 schema。
- ASR：stored attack-goal hit 与 executed attacker-tool trace 的并集。
- Utility：`[0,1]` 分级完成度；Task Success 要求全部正常工具完成。

| Method | Utility | Task Success | ASR | Safety |
|---|---:|---:|---:|---:|
| No Defense | **0.887** | **0.779** | 0.902 | 0.098 |
| Delimiter | 0.873 | 0.770 | 0.863 | 0.137 |
| Instructional Prevention | 0.880 | 0.775 | 0.397 | 0.603 |
| Observation Sandwich | 0.880 | 0.770 | 0.279 | 0.721 |
| TS-Flow | 0.855 | 0.735 | 0.191 | 0.809 |
| Progent-ASB | 0.860 | 0.730 | 0.034 | 0.966 |
| DRIFT-ASB | 0.858 | 0.730 | 0.230 | 0.770 |
| CLAFR | 0.868 | 0.735 | **0.000** | **1.000** |

可写结论：CLAFR 不是无防御 Utility 第一；它在强安全 baseline 中取得最高 Utility 和最低 ASR。相对 Progent-ASB，Utility `+0.008`、Task Success `+0.005`、ASR `-0.034`。

ASR=0 审计：488 个 proposed calls 中 394 个执行、94 个阻断；执行调用平均 signed margin `+0.134`，阻断调用 `-0.885`。该结果不是全拒绝。

来源边界 stress：保留 `source_trust` 时攻击调用可行 `0/200`、正常调用 `380/400`；去掉来源信息后攻击调用可行升到 `115/200`，正常调用仍为 `380/400`。结论是新环境必须提供运行时来源边界，而不是提供 attack 标签。

## 5. GPT-5.4-mini 跨 LLM 结果

- Benchmark：AgentDojo v1.2.2，同一 71 clean / 585 attack、四-suite协议。
- CLAFR：656 cases 全量实跑。
- Baselines：复用 Word 中前三-suite宏平均，并实跑 workspace 14/196。
- 正确聚合：`M4 = (3 * M_base3 + M_workspace) / 4`，不是按 71/585 case 数加权。
- 算法冻结：特征、几何权重、风险预算、阈值均未按模型调整。

| Method | Clean Utility | Static ASR | Static Attack Utility |
|---|---:|---:|---:|
| No Defense | 72.2 | 5.2 | 61.2 |
| Sandwich | **80.6** | 2.1 | 65.4 |
| Reminder | 76.6 | 0.6 | **65.4** |
| Spotlighting | 70.5 | 2.5 | 62.7 |
| PIGuard | 46.3 | **0.0** | 34.4 |
| ProtectAI | 48.9 | 2.3 | 38.6 |
| Progent | 66.0 | 1.4 | 54.2 |
| DRIFT | 41.7 | 0.2 | 38.8 |
| CLAFR | 68.7 | **0.0** | 59.5 |

可写结论：冻结 CLAFR 在第二个 function-calling LLM 上保持 0.0 ASR；其 Clean/Attack Utility 显著高于同为 0 ASR 的 PIGuard，并在三个公共指标上支配 Progent 和 DRIFT。Sandwich/Reminder 的 Utility 更高但 ASR 非零。GPT 上的任务能力低于 DeepSeek，论文不写成 CLAFR 在 GPT 上全面第一。
