ASR=0 审计：488 个候选调用中 394 个执行、94 个阻断；执行动作平均 signed margin `+0.134`，阻断动作 `-0.885`。因此该结果不是靠全拒绝获得。

## 3. AgentDojo 四模块消融

协议：四 suite，固定 seed，按 user task 做 outcome-independent SHA-256 三分之一抽样；每行 25 clean / 208 attack。Full 来自全量 run 的同一冻结子集，两个职责变更行已正式重跑。

| Method | Clean Utility | Static ASR | Static Attack Utility | Margin | Cases |
|---|---:|---:|---:|---:|---:|
| CLAFR | **91.4** | **0.0** | 79.1 | 0.686 | 25/208 |
| w/o Evidence Projection | 81.4 | **0.0** | 77.1 | 0.688 | 25/208 |
| w/o Action-Evidence Lifting | **91.4** | 1.4 | **82.2** | N/A | 25/208 |
| w/o Dynamic Geometry | 87.9 | 18.4 | 79.6 | N/A | 25/208 |
| w/o Decision & Repair | 77.3 | 1.5 | 79.2 | 0.686 | 25/208 |

模块归因：

- Evidence Projection：Clean Utility `+10.0`、Attack Utility `+2.0`，主要贡献是可信状态 grounding。
- Action-Evidence Lifting：ASR `-1.4`，提供较小但可测的安全贡献。
- Dynamic Geometry：ASR `-18.4`、Clean Utility `+3.5`，是主要安全模块。
- Decision & Repair：Clean Utility `+14.1`、ASR `-1.5`，主要恢复任务效用并提供次级安全收益。

Attack Utility 在去除 Lifting 或 Geometry 后小幅升高，是放松安全约束造成的效用-安全权衡；不能把消融要求写成每个模块必须无条件改善全部指标。

## 4. 论文可用结论

1. AgentDojo：CLAFR 达到 0.0 Static ASR 和最高 Static Attack Utility 81.4，同时保留 87.5 Clean Utility。
2. ASB：CLAFR 以 0.868 Utility、0.735 Task Success 和 0.000 ASR 优于同协议的强安全 baseline。
3. 消融：四个模块均改变至少一个公共指标；Dynamic Geometry 是最大安全贡献，Evidence Projection 和 Decision & Repair 分别承担状态 grounding 与效用恢复。
4. Margin：执行与阻断动作在 signed margin 的正负号上分离，为动态可行域提供机制审计证据。

泛化边界：这些结果支持跨 AgentDojo 与 ASB 的迁移，但不构成对任意新 benchmark 的保证。新环境必须通过通用 adapter 提供工具 schema、provenance、授权与状态证据；核心算法不得读取 benchmark 名称或 normal/attack 标签。
