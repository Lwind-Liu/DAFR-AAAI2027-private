# 历史实验说明

本目录保存项目开发阶段形成的中文实验方案、结果证据、模块职责和修改决策文档。

部分文档记录了原工作区中的历史绝对路径，例如 `C:\Users\...\AAAI\ICLR\...`。这些路径用于保留实验来源，不是当前仓库的运行命令。当前路径对应关系如下：

| 历史路径 | 当前路径 |
|---|---|
| `ICLR/src/clafr/` | `src/clafr/` |
| `ICLR/scripts/` | `scripts/` |
| `ICLR/tests/` | `tests/` |
| `ICLR/manifests/` | `data/manifests/` |
| `ICLR/results/...` | 已选结果位于 `results/summaries/` 和 `release_assets/`；新运行临时写入 `results/runs/` |

实际运行前应以根目录 [`README.md`](../../README.md)、[`docs/CODE_GUIDE.md`](../CODE_GUIDE.md) 和当前脚本参数为准。
