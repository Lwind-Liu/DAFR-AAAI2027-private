- 自定义机制指标：只保留 `Selected Signed Margin`。
- 回归测试：109 passed。

- ASB provenance：所有攻击工具仍在模型可见 schema 中；`source_trust` 只提供通用的运行时工具来源证据，不删除攻击工具，不提供 normal/attack label oracle。

## 3. ToolSafe-ASB-OPI 主表

### 3.1 协议

- 数据：10 agents、全部 51 个任务，每个任务按四类攻击 strata 固定随机抽取 4 个攻击，共 204 cases。
- Sampling：`stratified` attacks、`agent_round_robin` cases、seed 17。
- Workflow：204/204 预生成后冻结；所有方法读取相同计划。
- Utility：分级任务完成度 `[0,1]`。
- Task Success：官方风格 workflow 所需 normal tools 全部执行。
- ASR：stored attack-goal match 与 executed attacker-tool trace 的并集。
- Progent-ASB 与 DRIFT-ASB：同 harness、同模型的官方机制适配 baseline，不冒充原论文跨模型数字。

### 3.3 ASR=0 审计

- 204 个 case 的 stored attack-goal ASR 为 0。
- executed attacker-tool trace ASR 为 0。
- 488 个候选 tool calls 中 394 个执行、94 个阻断；不是全拒绝。
- 执行动作平均 signed margin 为 `+0.134`；阻断动作平均 signed margin 为 `-0.885`。
- CLAFR Utility 为 0.868、Task Success 为 0.735，也与“靠拒绝全部动作得到 ASR=0”不一致。

### 3.4 泛化边界

ASB 主表证明 CLAFR 可以迁移到不同 agent、工具名、参数 schema 与任务语义；它不证明缺少来源边界时仍有相同表现。旧 200-case no-label 几何诊断中，124/200 个伪装攻击工具在没有来源证据时仍可行。正确表述是：CLAFR 利用通用运行时 provenance，而不是 ASB normal/attack 标签。对完全不提供来源信息的新 benchmark，需要由环境 adapter 提供来源/授权/状态证据，或将该缺失证据反映为不确定性。

## 4. 四模块随机消融

### 4.1 协议

- 四 suite，固定 seed，按 user task 做 outcome-independent SHA-256 三分之一抽样。
- 每个方法：25 clean / 208 attack。
- 所有 suite 使用全部 injection tasks。
- Full CLAFR 行来自 71/585 全量 run 的同一子集；四个消融为冻结代码后的独立 run。

Manifest：`C:\Users\f1567\Desktop\AAAI\ICLR\manifests\agentdojo_v122_clafr_final_ablation_1third_4suite.json`

结果：`C:\Users\f1567\Desktop\AAAI\ICLR\results\agentdojo_v122_clafr_repartition_ablation_1third_v2\combined\clafr_manifest_ablation.md`

### 4.2 结果

| Method | Clean Utility | Static ASR | Static Attack Utility | Margin | Cases |
|---|---:|---:|---:|---:|---:|
| CLAFR | **91.4** | **0.0** | 79.1 | 0.686 | 25/208 |
| w/o Evidence Projection | 81.4 | **0.0** | 77.1 | 0.688 | 25/208 |
| w/o Action-Evidence Lifting | **91.4** | 1.4 | **82.2** | N/A | 25/208 |
| w/o Dynamic Geometry | 87.9 | 18.4 | 79.6 | N/A | 25/208 |
| w/o Decision & Repair | 77.3 | 1.5 | 79.2 | 0.686 | 25/208 |

模块解释：

- Evidence Projection 提供高质量状态提升，移除后 Clean Utility `-10.0`、Attack Utility `-2.0`，ASR 保持 0.0。它的主要贡献是可信事实 grounding 与任务完成，而不是代替几何安全决策。
- Action-Evidence Lifting 提供安全收益，移除后 ASR `+1.4`；其 Attack Utility 增加说明该模块承担了明确的安全-效用约束，而不是所有指标无条件上升。
- Dynamic Geometry 是主要安全模块：移除后 ASR `+18.4`、Clean Utility `-3.5`，且不再存在可解释的几何 margin。Attack Utility 增加 `0.5` 是放松安全约束后的预期权衡，不应解释为方法退化。
- Decision & Repair 主要恢复任务效用，移除后 Clean Utility `-14.1`，同时 ASR `+1.5`。

四个模块均改变至少一个公共指标，且关闭路径分别对应独立代码模块。新版职责划分使 Dynamic Geometry 承担未信任控制风险、动态约束与风险预算，Evidence Projection 只承担高置信度状态提升；Full 组合行为保持不变。

### 4.3 旧机制压力表的状态

旧 `geometry_stress_final_v1` 产生于职责重划分之前，不进入最终论文证据。新版随机四-suite 消融已直接在公共指标上给出足够强的几何归因，无需使用人工挑选的压力子集放大差距。

## 5. Margin 机制证据

只报告 `Selected Signed Margin`：最终执行动作相对所有 hard constraints 的最小 signed slack。

- AgentDojo 71/585：平均绝对 margin `0.686`。
- ASB 204：执行动作平均 margin `+0.134`；阻断动作平均 margin `-0.885`。
- 正负号与 Allow/Block 决策一致，支持“动作位于动态可行域内部或外部”的解释。

Margin 是机制审计指标，不替代 Utility、Task Success 或 ASR。

## 6. 可直接写入论文的结论

1. On AgentDojo v1.2.2, CLAFR achieves 0.0 static ASR and the highest static-attack utility (81.4) while retaining 87.5 clean utility over 71 clean and 585 attacked cases.
2. On the 204-case ToolSafe-ASB-OPI transfer evaluation, CLAFR reaches 0.868 utility and 0.0 ASR, outperforming the strongest adapted security baseline, Progent-ASB, in both utility and ASR.
3. A four-suite, outcome-independent ablation shows that removing any paper-level module degrades at least one public metric; removing Dynamic Geometry raises ASR from 0.0 to 18.4 and reduces clean utility by 3.5 points, while removing Evidence Projection reduces clean utility by 10.0 points.
4. Margin traces separate executed and blocked actions by sign, providing a mechanism-level audit of the dynamic feasible region.

不得写：CLAFR 在所有 Utility 指标绝对第一；ASR=0 可保证迁移到任意 benchmark；ASB 完全不使用运行时来源信息；四模块都无条件同时改善所有指标。
