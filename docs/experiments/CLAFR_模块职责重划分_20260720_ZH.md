# CLAFR 模块职责重划分

日期：2026-07-20

## 1. 目的

旧消融把多项运行时必需能力同时归入 Evidence Projection：可信事实状态、未信任控制识别、风险隔离提示、opaque ID 还原。关闭该模块不仅移除了论文机制，也破坏了合法工具调用的执行条件，因而得到过大的 Utility 降幅；同时 Dynamic Geometry 仍受 projection 的风险提示保护，公共指标贡献被低估。

本次修改只重划模块所有权，不改变 Full CLAFR 的组合算法。

## 2. 新职责

| 组件 | 新职责 |
|---|---|
| Evidence Projection | 将工具结果提升为字段级、高置信度可信状态；`state_freshness=1.0` |
| Dynamic Geometry | 检测未信任控制内容、维护风险坐标、生成风险隔离提示，并在没有结构化 projection 时保留低置信度事实回退；`state_freshness=0.65` |
| Action-Evidence Lifting | 将候选调用与当前证据提升为动作-证据向量 |
| Decision & Repair | 根据 margin 执行 Allow/Block/Clarify 和通用 repair |
| Runtime State Adapter | opaque ID 与真实运行时参数的双向还原；属于执行 plumbing，不进入论文消融 |

## 3. Full 不变量

Full CLAFR 仍按以下顺序执行：

1. 投影可信事实状态。
2. 检测并隔离未信任控制内容。
3. 构造同一动作-证据特征向量与动态约束。
4. 使用同一 selector、margin 和 repair。
5. 使用同一 opaque 参数还原后执行工具。

因此 AgentDojo 与 ASB 的 Full 主表结果仍属于当前算法。需要重跑的是发生定义变化的 `w/o Evidence Projection` 与 `w/o Dynamic Geometry` 两行，而不是 Full 主表。

## 4. 新消融语义

### w/o Evidence Projection

- 不生成字段级、高置信度可信状态。
- Dynamic Geometry 仍检测控制内容、隔离风险，并保留低置信度事实关系。
- opaque 参数仍可正确执行。
- 该反事实测试“高质量状态提升”的增益，不再等价于完全看不到 observation。

### w/o Dynamic Geometry

- Evidence Projection 仍能提取可信事实。
- 不检测/累计未信任控制风险，不生成 geometry-conditioned 隔离提示。
- 关闭 semantic facets、confidence floor 与 privacy/financial/state-write risk budgets，仅保留 schema verifier。
- 该反事实真正移除了动态几何决策机制。
